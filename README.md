# dbs-user-app

ドコモ・バイクシェアのカスタムプラン利用者向け画面。**GitHub Pages で配信する外側だけ**を置く。

## このリポジトリに入れてよいもの / いけないもの

| | |
|---|---|
| 入れてよい | HTML / CSS / JavaScript（画面の作りだけ） |
| **入れてはいけない** | 請求データ、利用履歴、ユーザ識別番号、エリア識別子、認証情報 |

**このリポジトリは公開される。** 請求データは R2（非公開）に置き、Cloudflare Worker が
鍵を確認したうえで返す。`.gitignore` が `*.json` を丸ごと除外しているのは、
表示用データを誤ってコミットする事故を機械的に防ぐためである。

## 変更のしかた

画面の正本は `dbs-custom-plan/app/` にある。**ここのファイルを直接編集しない。**
正本を直してから同期する（同期手順は `dbs-custom-plan` 側の運用手順を参照）。
直接編集すると、正本のテスト（`tests/test_app_contract.py` の
「innerHTML を使わない」「外部URLを参照しない」検査）を通らない変更が
公開側にだけ入り、検査をすり抜ける。

## 動作確認

```
python -m http.server 8000
```

ブラウザで `http://localhost:8000/` を開く。データの取得先は別途設定する。
